# Home Network Security Assessment

## Project Overview

This project documents a security assessment of a residential home network. The assessment was conducted to identify potential security risks, evaluate network configurations, and recommend improvements based on cybersecurity best practices.

## Objectives

* Inventory all devices connected to the network
* Review wireless security settings
* Verify endpoint security protections
* Assess overall network security posture
* Provide recommendations for risk reduction

## Tools Used

* Windows Command Prompt
* Windows Security
* Home Router Administration Interface
* Draw.io / Canva
* Microsoft Word

## Assessment Activities

### Network Inventory

Identified and documented devices connected to the home network, including computers, mobile devices, and smart devices.

### Wireless Security Review

Evaluated Wi-Fi encryption settings, password security, and router configuration.

### Endpoint Protection Review

Verified antivirus status, firewall settings, and operating system updates.

### Risk Assessment

Identified potential vulnerabilities and provided recommendations to improve network security.

## Key Findings

* Antivirus protection was enabled and operational.
* Windows Firewall was enabled.
* Network-connected devices were successfully inventoried.
* Wireless security settings were reviewed and documented.

## Recommendations

* Maintain regular operating system and software updates.
* Review connected devices periodically.
* Use strong, unique passwords for network access.
* Enable WPA3 encryption if supported by network equipment.
* Monitor network activity for unauthorized devices.
